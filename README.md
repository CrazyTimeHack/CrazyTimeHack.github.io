# Crazy Time Forecaster website

## Publish with GitHub Pages

1. Create a free GitHub account at https://github.com/
2. Create a new **public** repository named:
   `YOUR-USERNAME.github.io`
3. Upload these four files:
   - index.html
   - style.css
   - robots.txt
   - sitemap.xml
4. In the repository open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Your site will be available at:
   `https://YOUR-USERNAME.github.io/`

## Before publishing

Replace `YOUR-USERNAME` in:
- index.html
- robots.txt
- sitemap.xml

Replace `[TARGET COUNTRY]` in index.html with the country you want to target.

The website already links to:
https://t.me/CrazyTimeForecaster

Do not add unsupported claims such as guaranteed wins or guaranteed prediction accuracy.
